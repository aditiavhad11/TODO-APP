
# 📝 To-Do List App

A simple and responsive To-Do List web application built using **HTML**, **CSS**, and **JavaScript**. <br>
Users can add tasks, mark them as completed, and delete them. It also shows task statistics including total tasks, completed tasks, and success rate.

---
## 🔧 Features

- ✅ Add new tasks  
- 🗑️ Delete tasks  
- ✔️ Mark tasks as completed  
- 📊 Display task statistics:
  - Total tasks  
  - Completed tasks  
  - Success percentage  

---
## 💻 Technologies Used

- HTML5  
- CSS3  
- JavaScript
